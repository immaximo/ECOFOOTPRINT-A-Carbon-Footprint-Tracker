# **App Name**: EcoTrack Alangilan

## Core Features:

- Data Input: Allow building administrators to input monthly data on electricity, water, and waste usage for BatStateU Alangilan campus.
- Carbon Emission Calculation: Automatically calculate the total carbon emissions based on the input data using predefined conversion factors.
- Campus-wide Dashboard: Display interactive campus-wide dashboards visualizing carbon emissions data, trends, and comparisons across buildings.
- Data Validation: Ensure data accuracy by implementing input validation and anomaly detection, alerting admins when unusual values are entered.
- Trend Analysis: Provide trend analysis to visualize the historical carbon footprint data and identify areas of improvement. Use the LLM as a tool to evaluate areas to improve.

## Style Guidelines:

- Primary color: Forest green (#386641) to represent sustainability and nature.
- Background color: Very light green (#F0F5F1) to create a clean and eco-friendly feel.
- Accent color: Earthy brown (#A68A64) for secondary elements and highlights, symbolizing stability.
- Body and headline font: 'PT Sans' for a modern and readable look.
- Use clean and simple icons related to energy, water, and waste management.
- Design a clear and intuitive layout with prominent dashboards and easy-to-navigate data input forms.
- Use subtle animations to visualize data trends and highlight key metrics on the dashboards.
